# LoadForge UI — Веб-интерфейс

Фронтенд платформы нагрузочного тестирования LoadForge. Предоставляет визуальный интерфейс для управления сценариями, запуска тестов и просмотра результатов.

## Технологии

- **React 18 + TypeScript**
- **Vite 6** — сборщик и дев-сервер
- **Tailwind CSS 4 + shadcn/ui** — компоненты интерфейса
- **@xyflow/react (React Flow)** — визуальный редактор графов сценариев
- **recharts** — графики метрик
- **pnpm** — пакетный менеджер

## Что делает

- **Редактор сценариев** — визуальное построение графов нагрузочного теста (узлы: HTTP, DELAY, CHECK, GENERATE и др.) с drag-and-drop
- **Управление тестами** — создание запусков, выбор профиля нагрузки, отслеживание статуса в реальном времени
- **Агенты** — мониторинг подключённых агентов, их состояния и ресурсов
- **Отчёты** — просмотр и экспорт результатов завершённых тестов (PDF)
- **Аутентификация** — JWT-based вход, ролевой контроль доступа

## Запуск

```bash
npm install
npm dev
```

Интерфейс доступен на `http://localhost:5173`. Запросы к API проксируются на `http://localhost:8080`.

## Сборка

```bash
npm build
```
